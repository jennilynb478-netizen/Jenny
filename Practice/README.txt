77 Birch Court — Animated Real Estate Landing Page

Included:
- index.html: full responsive website with CSS and JavaScript included
- images/: add the four real property photos here

Add actual photos:
1. images/front.jpg
2. images/living-room.jpg
3. images/kitchen.jpg
4. images/balcony.jpg

Then edit index.html. For each gallery item, replace the inner <div class="photo-placeholder">...</div>
with the matching image tag, e.g.:
<img src="images/front.jpg" alt="Front exterior of 77 Birch Court, Unit 4" loading="lazy">

Keep the existing <span class="photo-tag">Front Exterior</span> after the image.
Repeat for each photo with appropriate alt text. This prevents any invented or stock imagery.

Animations:
- Scroll reveal/fade-up effects
- Photo zoom on hover
- Button hover transitions
- Reduced-motion accessibility support

Deploy on Netlify for free:
1. Extract the ZIP.
2. Add the real property photos and replace placeholders as described.
3. Visit https://app.netlify.com/drop and sign in to a free Netlify account.
4. Drag the folder containing index.html into Netlify Drop.
5. Open the provided URL on desktop and phone to test.

No paid domain or upgrade is required. The phone number is linked for call/text on supported devices.
